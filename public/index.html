Privacidade e Protecao de Dados (LGPD)

Politica de Privacidade - MBF Estoque

O MBF Estoque utiliza dados pessoais para identificar usuarios, controlar o acesso ao sistema e registrar movimentações de materiais.

Dados utilizados

Nome, nome de usuario, setor, perfil de acesso e registros de atividades realizadas no sistema.

Seguranca

As senhas sao protegidas por hash criptografico. O acesso as funcionalidades depende das permissoes atribuidas a cada usuario.

Finalidade

Os dados sao utilizados para autenticacao, administração de usuários, controle de estoque e auditoria das operacoes.

Direitos dos usuarios

Os usuarios podem solicitar informações e correcoes sobre seus dados pessoais ao responsavel pelo sistema.

Esta politica faz parte de um projeto academico e nao representa, isoladamente, conformidade integral com a LGPD.
